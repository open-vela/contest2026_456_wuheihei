# 阶段 2：复现实验与指标

## 1. 评测口径

以下指标由 `training/train_edge_mfcc.py` 在 ESC-50 官方五折上重新训练与评测得到。

- 交叉验证：ESC-50 官方五折
- 防止泄漏：同一源录音切出的多个一秒窗口全部位于同一折
- 统计单位：源录音（同一源录音的多个一秒窗口归为一条）
- 评测规模：390 条源录音、1,950 个窗口
- 训练设置：120 epochs、隐藏层 64、随机种子 42、类别权重指数 0.5
- 数据增强：混合增强，增强副本数 4；事件类使用 75% 增强样本，background 使用 25%；混合同训练折真实背景，背景只从训练折内取
- 噪声条件：clean、20 dB、10 dB、5 dB
- Float 与 INT8 使用相同折和相同样本

这些指标属于离线评测，不是开发板实测准确率。

## 2. 五折结果

| 测试折 | Clean Float 总体准确率 | Clean Float 宏平均召回率 |
|---:|---:|---:|
| 1 | 83.33% | 75.58% |
| 2 | 84.52% | 73.85% |
| 3 | 86.11% | 85.00% |
| 4 | 77.78% | 80.00% |
| 5 | 80.77% | 76.96% |
| 汇总 | 82.56% | 78.39% |

这里的“汇总”来自拼接五折各自测试集后的统一混淆矩阵，即按全部 390 条源录音统一计算。

## 3. 总体结果

| 条件 | Float 总体准确率 | Float 宏平均召回率 | INT8 总体准确率 | INT8 宏平均召回率 |
|---|---:|---:|---:|---:|
| Clean | 82.56% | 78.39% | 82.56% | 78.39% |
| 20 dB | 80.00% | 78.76% | 80.00% | 79.17% |
| 10 dB | 79.23% | 80.57% | 79.23% | 80.15% |
| 5 dB | 74.36% | 74.37% | 74.87% | 74.54% |

INT8 与 Float 结果基本一致，未观察到明显精度损失。

## 4. 各类别召回率（Float）

| 条件 | background | cough | glass_break | baby_cry | dog_bark |
|---|---:|---:|---:|---:|---:|
| Clean | 86.96% | 55.00% | 85.00% | 85.00% | 80.00% |
| 20 dB | 81.30% | 52.50% | 92.50% | 87.50% | 80.00% |
| 10 dB | 77.83% | 57.50% | 82.50% | 95.00% | 90.00% |
| 5 dB | 74.35% | 47.50% | 82.50% | 90.00% | 77.50% |

5 dB 下五类事件均可检出，其中 cough 召回率最低（47.50%）。

## 5. 模型体积

- 参数量：6,277
- Float32 参数和归一化数据：25,844 字节
- INT8 权重存储估算：7,029 字节
- 估算缩减：72.80%

该数值为模型参数与归一化常量的存储估算，不含固件体积与运行时内存。

## 6. C 主机模拟器验证

主机 C 模拟器复用 `app/audiodetect/` 的 C 特征提取与三秒决策逻辑，配合 `simulator/` 的 INT8 推理实现，可在 Linux 主机上独立构建运行。

```bash
python training/export_to_c.py
./scripts/build_robust_c_simulator.sh
./out/robust-simulator/audiodetect_robust_sim /path/to/16k_mono_16bit.wav
```

该验证用于确认部署 C 链路可导出、可编译、可运行，以及静音门限与三秒决策逻辑符合设计；样本级结果不作为模型准确率。

## 7. 复现结论

1. `training/export_to_c.py` 从项目模型生成的三个权重头文件与模型逐值一致（float32 完全一致，INT8 为对称逐张量量化的确定性结果）。
2. 五折 Clean Float 总体准确率为 82.56%，宏平均召回率为 78.39%。
3. INT8 五折总体准确率为 82.56%，未观察到精度下降。
4. glass_break 与 baby_cry 召回较高；cough 在各噪声条件下均为最弱类别。
5. 10 dB、5 dB 条件下五类事件仍可检出，但 cough 召回率下降明显。
6. C 主机模拟器可独立导出并构建，未产生真实开发板准确率、延迟、内存或功耗数据。
