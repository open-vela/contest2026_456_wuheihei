# OpenVela 端已实现与未实现功能

本文件只根据冻结的 v10 源码、配置和镜像陈述，不推测未留下证据的功能。

## 已实现

### 1. 板级集成与启动

- 已集成到 OpenVela `apps/audiodetect`。
- 已启用 R528S3 Gemini S1、Audio、PCM、LCD、触摸和 LVGL 配置。
- 已生成最新真实板镜像 `nuttx.bin`。
- 已在板级 `rcS.nsh` 中配置自动启动：硬件初始化后等待 3 秒，执行 `audiodetect ui &`。
- UI 初始化会重试最多 8 次，显示或触摸设备未就绪时返回错误。

### 2. 实时音频采集

- UI 工作线程调用系统 `arecord`。
- 采样格式固定为 16 kHz、16-bit、单声道。
- 每次采集 3 秒到 `/data/aed_live.wav`。
- 每段拆分为最多三个一秒模型窗口。

### 3. 离线端侧推理

- 92 维特征提取在 C 端完成。
- 使用 `92 → 64 → 5` TinyMLP。
- UI 实时路径使用 INT8 权重存储和 C 前向推理。
- 五类输出：background、cough、glass_break、baby_cry、dog_bark。
- 输入能量低于 `2.0e-5` 时直接判为 background，避免安静环境被强制分类成事件。
- 三秒内选择置信度最高的非背景窗口；非背景置信度达到 0.80 才作为事件输出，否则使用三窗口平均概率。

### 4. 本地界面

- LVGL 本地界面，源码布局面向 320×240 级显示区域。
- 显示工作状态：READY、LISTENING、ANALYZING、PAUSED、ERROR。
- 显示当前类别、置信度、能量、处理段数和告警数。
- 提供 START、STOP 和 AUTO 控件。
- AUTO 状态写入 `/data/aed_autostart`，重启后读取。
- 内存中保留最近 3 条事件摘要。

### 5. 命令行能力

- 可对 16 kHz 单声道 WAV 做 Float32 或 INT8 推理。
- 提供 Clean/20/10/5 dB 鲁棒性演示命令。
- 包含“救命、帮助、报警”三个关键词的 MFCC+DTW 命令行识别路径。
- 包含 HTTP/MQTT 告警上报代码路径，命令行需显式传入 `--report`。

## 已有代码但不能声明为真实板完整功能

### 1. 远程 HTTP/MQTT 告警

代码存在于命令行路径，但实时 UI 工作线程没有调用远程上报；本次也没有找到可核验的服务器接收日志。因此只能写“提供可选代码路径”，不能写“实时告警已经在真机完整打通”。

### 2. 关键词识别

关键词识别存在于命令行 WAV 输入路径，没有接入实时三秒监听 UI，也没有本次真机验证日志。因此不能写成实时常驻关键词功能。

### 3. 真机运行效果

当前源码、目标配置、编译对象和最终镜像均存在，可以声明完成真实板代码适配和镜像构建。但本阶段没有重新连接开发板，也没有生成新的串口日志、运行录像或测量数据。

服务器中已有的 Goldfish 镜像早于 v10。本阶段没有使用该旧镜像冒充当前版本，C 验证采用重新编译当前源码的 Linux 主机模拟器。

## 未实现或未验证

- 没有直接使用持续 PCM/I2S 环形缓冲；当前通过 `arecord` 分段写临时 WAV，段与段之间可能存在间隔。
- 没有重叠滑窗和事件起止时间定位。
- 每个窗口只输出一个类别，不支持多标签并发事件。
- UI 没有实际创建五个类别的独立概率条；结构中虽有预留字段，但当前界面只显示最终类别和总置信度。
- 最近事件历史只保存在内存，重启后不保留。
- 没有本地数据库、音频证据归档或日志导出界面。
- 没有把 HTTP/MQTT 上报接入实时 UI 监听流程。
- 没有在设备端训练、增量学习或模型在线更新。
- 没有 OTA 更新流程。
- 没有真实板五类准确率测试。
- 没有真实板端到端延迟、推理耗时、峰值内存和功耗测量。
- 没有长时间连续运行、异常恢复和压力测试数据。
- 没有对不同麦克风、距离、方位和真实房间混响做系统性真机评测。

## 已发现的文档一致性问题

- 当前应用 `README.md` 早于实时 UI 实现，仍写着需要将 WAV 读取替换为麦克风输入；实际 v10 已通过 `arecord` 实现三秒麦克风采集。
- Kconfig 帮助文字写“1024×600 LVGL 界面”，但当前 UI 代码使用 320 像素宽、约 232 像素高的布局，板级配置也是 ILI9341。正式提交 README 和报告应按源码事实描述为 320×240 级界面，不能照抄旧帮助文字。

这两项属于文档问题。本阶段为保持 v10 冻结没有修改原源码，阶段 3 整理官方仓库时再修正文档。
